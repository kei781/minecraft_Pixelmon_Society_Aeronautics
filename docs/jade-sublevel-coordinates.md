# Jade와 비행체 좌표 검증

실제 조립된 비행체에서 꺼진 레버를 조준하자 Jade 11.13.2가 월드 좌표 약 23과 저장 공간 좌표 약 20,481,037을 함께 사용했다. Sable의 큰 탐색 상자 보호가 요청을 중단했고, 클라이언트는 종료되지 않았다. 최초 오류와 당시 상태는 [기록](../evidence/jade-sublevel-raytrace-baseline.json)에 남겼다. 비행은 아직 검증하지 않았다.

호환 코드는 Jade의 계산용 hit 위치 읽기 다섯 곳을 월드 좌표로 투영한다. 반환하는 원래 hit 결과와 블록 위치는 유지한다. 내부 엔티티의 충돌 상자는 해당 비행체 좌표에서 contains/clip을 실행하고, 교차점은 월드 좌표로 돌려 거리 비교에 사용한다. 카메라와 기존 렌더 결과를 사용하는 동안 Sable의 렌더 pose 문맥을 설정하고 예외가 발생해도 finally에서 복원한다. 서버 블록 정보 요청은 두 정수 위치를 월드 좌표로 투영해 기존 거리 제한과 비교한다. 원래 거리 한계·로드 검사·엔티티 조건·큰 탐색 보호는 바꾸지 않는다.

일반 월드에서는 기존 contains/clip 호출과 서버 거리 계산을 그대로 호출한다. Jade가 없으면 두 선택적 대상 믹신은 적용되지 않는다. 고정 Jade 클래스에서 hit 위치 5곳, contains 1곳, clip 1곳, 서버 거리 1곳을 지정했다. 다른 버전에 추측으로 적용하지 않는다.

실제 Minecraft AABB와 Sable/JOML을 사용한 36개 기하 검사가 통과했다. 독립 소스 트리 두 곳에서 빌드·재난독화·ZIP 정규화한 결과도 동일하다. [빌드 기록](../evidence/jade-coordinate-candidate-build.json)의 런타임 상태는 별도로 구분한다. 기하 검사만으로 실제 조준과 서버 블록 정보 요청을 통과했다고 판단하지 않는다.

전체 354개 모드, 내장 JAR 75개, 클래스 79,468개에서 hit 위치와 관련 기하 API의 참조를 검색했다. 후보 33개를 추가로 분류한다. 이 검색은 데이터 흐름이나 전체 모드 호환성의 증명이 아니다. 특히 다른 모드의 거리·발사체·시점 계산은 해당 기능의 실제 회귀 검증을 계속해야 한다.

테스트 전용 Jade 관찰 도구는 실제 엔티티 탐색 호출이 반환한 뒤 입력 상자의 범위와 시작·끝 좌표를 기록한다. 원래 호출·조건·반환값을 변경하지 않는다. 좌표 차이에 따른 진단 분류는 실제 프레임 조회의 증명과 구분한다. 이 JAR는 배포 팩에 포함하지 않는다.

사용한 주입 API는 [MixinExtras의 공식 설명](https://github.com/LlamaLad7/MixinExtras/wiki/ModifyExpressionValue)에 따르며, 실제 포함된 0.4.1을 대상으로 빌드했다.
